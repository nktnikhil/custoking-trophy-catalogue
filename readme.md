# Custoking Trophy Catalogue

A static, responsive trophy catalogue for Custoking.

## Features

- One product card per trophy model
- All available sizes shown in a dropdown
- Size and price displayed together
- Selected size changes displayed price
- Starting price taken directly from JSON
- Sorting based ONLY on startingPrice
- Low-to-high starting price
- High-to-low starting price
- Search by model
- Trophy / Economic Trophy filter
- Minimum starting price
- Maximum starting price
- WhatsApp enquiry
- Responsive desktop and mobile design
- GitHub Pages compatible
- No backend required
